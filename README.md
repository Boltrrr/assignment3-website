Feature Checklist:

Request 1 – Responsive Navigation with Hamburger Menu  
The site navigation collapses into a hamburger menu on screens smaller than 768px.

Request 2 – Form Validation with Error Messages  
The contact form validates name, email, and message fields, as well, errors appear beside the fields and disappear once corrected.

Request 3 – Back to Top Button  
A button appears after scrolling down the page and smoothly scrolls the user back to the top.

Request 4 – Dynamic Content Rendering  
The Game Features section is generated from a JavaScript array of objects.

Request 5 – Accordion FAQ  
The About page contains a collapsible FAQ section where only one question can be open at a time.

Request 6 – Filtering / Search  
Users can filter game features by category and search using keywords. The site renders matching results dynamically.

Request 7 – Public API Integration  
The site fetches random game data using the RAWG public API and displays it as a featured inspiration section.
